# Clipboard Vault — архитектура версии 1.1

## Назначение

**Clipboard Vault** — нативное приложение macOS в строке меню, которое локально сохраняет историю текстовых и графических элементов буфера обмена. Изображения, включая скриншоты, сохраняются в PNG-файлы внутри каталога Application Support и показываются в истории с миниатюрами.

## Формат данных

| Элемент | Хранение |
|---|---|
| Текст | В `history.json` внутри поля `text`. |
| Изображение | В отдельном PNG-файле внутри `Images`; в JSON хранится имя файла, размер в пикселях и SHA-256-отпечаток. |
| Общие свойства | UUID, дата, закрепление и тип содержимого. |
| Старые записи | Старый JSON без поля `kind` автоматически трактуется как текстовая запись. |

Отдельные файлы изображений не встраиваются в JSON. Это предотвращает разрастание одного документа истории и позволяет удалять неиспользуемые PNG-файлы при каждом сохранении.

## Захват буфера

`PasteboardMonitor` проверяет счётчик изменений `NSPasteboard.general` каждые 0,75 секунды. Сначала он пытается получить обычный текст. Если текст отсутствует, он декодирует изображение через `NSImage`, преобразует его в PNG и передаёт в `ClipboardStore` вместе с шириной, высотой и SHA-256-отпечатком.

Одинаковые изображения не создают новые записи: отпечаток используется для перемещения уже существующей записи наверх истории. Скриншоты, скопированные стандартными средствами macOS, обрабатываются как обычные графические данные буфера и не требуют отдельного разрешения.

## Компоненты

| Компонент | Ответственность |
|---|---|
| `ClipboardVaultApp` | Точка входа SwiftUI и окно в строке меню. |
| `PasteboardMonitor` | Распознаёт текст и изображения в системном буфере. |
| `ClipboardStore` | Управляет историей, дедупликацией, поиском, копированием, закреплением и лимитом записей. |
| `HistoryPersistence` | Сохраняет JSON, PNG-файлы и удаляет осиротевшие файлы. |
| `ClipboardItem` | Codable-модель текстовой или графической записи с обратной совместимостью. |
| `ClipboardMenuView` | Интерфейс поиска и списка истории. |
| `ClipboardRowView` | Миниатюра изображения, метаданные и действия записи. |
| `SettingsView` | Настройки лимита и режима сохранения. |

## Приватность и ограничения

История не отправляется по сети. При включённом мониторинге изображения могут содержать конфиденциальные материалы, поэтому сбор рекомендуется приостанавливать перед копированием паролей, одноразовых кодов и других чувствительных данных. Команда очистки удаляет записи, а последующее сохранение удаляет PNG-файлы, на которые больше не ссылается история.

Версия 1.1 поддерживает обычный текст и изображения, преобразуемые macOS в `NSImage`/PNG. Форматированный текст, документы, произвольные файлы, исключения для отдельных приложений, глобальная горячая клавиша и синхронизация iCloud остаются за пределами текущей версии.

## Критерии готовности

Приложение должно сохранять новый текст или скриншот после изменения буфера, отображать миниатюру изображения, возвращать выбранное изображение в системный буфер и сохранять историю после перезапуска. Старый текстовый JSON должен загружаться без ручной миграции.
