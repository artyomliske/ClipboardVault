# Глобальная горячая клавиша истории

## Решение

Clipboard Vault использует нативный `RegisterEventHotKey` из Carbon для регистрации **одного точного пользовательского сочетания** во всей системе. В отличие от глобального монитора `NSEvent`, этот подход не требует выдавать приложению разрешение Accessibility на наблюдение за всеми нажатиями клавиш [1].

Горячая клавиша по умолчанию — **⌥⌘V**. Пользователь может записать другое сочетание в настройках; сочетание должно включать хотя бы один модификатор. Если macOS или другое приложение уже заняло его, Clipboard Vault сохраняет последнее рабочее сочетание и показывает ошибку регистрации.

## Поведение

| Событие | Действие |
|---|---|
| Нажатие сочетания | Открывает небольшое окно истории Clipboard Vault поверх активного приложения. |
| Повторное нажатие | Скрывает это окно. |
| Окно уже открыто | Получает фокус и остаётся доступно для поиска и выбора записи. |
| Выбор записи | Возвращает текст или изображение в системный буфер обмена. |
| Использование Menu Bar | Сохраняется без изменений; горячая клавиша не зависит от открытого меню. |

Окно истории реализуется через `NSPanel` с SwiftUI-содержимым. Это обходит ограничение `MenuBarExtra`: у него нет публичного API для программного открытия из глобального обработчика. Dock остаётся скрытым благодаря `LSUIElement = true`.

## Приватность

Обработчик получает уведомления только для зарегистрированного сочетания. Он не считывает и не записывает остальные нажатия клавиш, не использует сеть и не требует разрешений Accessibility.
